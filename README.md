# ⌨️ OG Pad

**OG Pad** is a custom hardware macropad created as part of the [Hack Club Hackpad](https://hackclub.com/) program. It features a custom PCB layout, personalized keymapping, and custom CAD enclosure design.

---

## 🛠 Features

* **Custom PCB**: Designed from scratch using KiCad.
* **Programmable Firmware**: Powered by QMK / KMK / ZMK firmware for custom layer switching and macro shortcuts.
* **3D Printed Case**: Custom CAD-designed enclosure tailored for ergonomic desktop use.
* **Hot-Swappable Switches**: Easy customization for mechanical switches and keycaps.
